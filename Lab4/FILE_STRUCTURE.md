## Version Control Notes

### Files to Commit
- Source code and templates (all .tf, .yml, .j2, .md, .sh files)
- Configuration examples (.example, .template files)
- Documentation

### Files to Ignore
- Generated files (Terraform state, lock files)
- Environment-specific variables (terraform.tfvars, hosts.ini)
- Application build artifacts (dist/, node_modules/)
- Temporary files

## Deployment Artifacts

After deployment, the following directories will exist on the VMs:
- **Worker**: `/opt/mywebapp/` (application)
- **Worker**: `/etc/nginx/sites-available/` (nginx config)
- **Worker**: `/etc/systemd/system/` (systemd units)
- **Database**: `/etc/mysql/conf.d/` (MariaDB config)

These are created by Ansible and NOT tracked in Git.
